# AR Invader Demo 👾

スマホのブラウザ（標準カメラ）だけで遊べる、インストール不要のWebARシューティングゲームです。
A-Frame と AR.js を使用しており、iOS (Safari) と Android (Chrome) の両方でシームレスに動作します。

## 🌟 特徴 (Features)

* **クロスプラットフォーム対応**: 専用アプリ不要。スマホのブラウザを開くだけですぐに遊べます。
* **快適なプレイ体験（マーカーロスト対策）**: ゲーム開始時にHiroマーカーを一度認識すれば、カメラからマーカーが外れてもゲーム盤が空間に残り続けます。
* **滑らかな位置補正 (Lerp)**: 再度マーカーを認識した際、カクつくことなく滑らかに正しい位置へ同期します。
* **高パフォーマンス (Object Pooling)**: 弾のオブジェクトを事前に生成して使い回す「オブジェクトプーリング」を実装。連射してもDOM操作による処理落ちが発生しません。
* **ECSアーキテクチャ**: A-Frameのコンポーネント指向（Entity-Component-System）に基づき、敵や弾のロジックをモジュール化して設計しています。

## 🎮 遊び方 (How to Play)

1. **アクセス**: スマホでデモページのURL（GitHub Pages等）を開きます。
2. **カメラ許可**: ブラウザの「カメラへのアクセス」を許可してください。
3. **マーカーを映す**: PCや別のスマホの画面に [Hiroマーカー](https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png) を表示し、カメラで映します。
4. **プレイ開始**: マーカーの上にARのゲーム盤とターゲット（赤い箱）が出現します。
5. **攻撃**: 画面中央の照準をターゲットに合わせ、画面下の「BEAM!」ボタンをタップして撃破してください！

## 🛠 使用技術 (Technologies)

* [A-Frame (v1.3.0)](https://aframe.io/): WebVR/WebARフレームワーク
* [AR.js](https://ar-js-org.github.io/AR.js-Docs/): Webブラウザ向け軽量ARライブラリ
* HTML5 / CSS3 / Vanilla JavaScript

## 💻 ローカルでの開発・動作確認

Webカメラを使用するため、**HTTPS環境**（または `localhost`）での実行が必須です。

1. このリポジトリをクローンまたはダウンロードします。
2. VS Codeの拡張機能「[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)」などを利用してローカルサーバーを立ち上げます。
3. PCブラウザ、または同一ネットワーク内のスマホからIPアドレス経由（HTTPS設定が必要）でアクセスします。
   ※一番簡単な方法は、GitHub Pagesにプッシュしてスマホから確認することです。
